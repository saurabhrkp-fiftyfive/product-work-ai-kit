# Estimation Benchmarks (reusable)

Hours from past projects — reused so new estimates start grounded, not from a blank guess.
Update after every project so the numbers sharpen over time.

| Task type | Typical hours |
|-----------|--------------:|
| CRUD screen (list + form) | 8–12 |
| Filterable report + export | 12–16 |
| Third-party integration (simple) | 16–24 |

_A reusable pattern lives in `knowledge/` because it outlives any single project._
