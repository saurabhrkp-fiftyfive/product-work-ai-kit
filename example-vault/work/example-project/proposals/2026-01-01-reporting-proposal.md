# Proposal — Example Project: Reporting Screen
**Date:** 2026-01-01
**Status:** locked

## Overview
A filterable reporting screen so the client's team can view and export operational data without engineering help.

## Epics
- **Reporting screen** — filterable table of records.
- **Export** — download the current view.

## Scope of work
Table with date-range and status filters; CSV export of the filtered view.

## Deliverables
- Reporting screen (v1)
- CSV export

## Acceptance criteria
- Filters apply to both table and export.
- Export matches the on-screen filtered rows.

## Prerequisites
- Read access to the reporting data source.
